プライバシーポリシー

Training Note Health ／ 最終更新: 2026年11月9日

対象

Training Note Health（以下「本ツール」）は、開発者本人だけが自分のデータを見るために使う個人用のツールです。一般のユーザーには提供していません。

取得するデータ

本ツールは、Google Health API から次のデータを読み取り専用で取得します。データの作成・変更・削除は行いません。

  • 睡眠（睡眠時間・睡眠段階）
  • 健康指標（安静時心拍数・心拍変動）
  • 活動とフィットネス（歩数・運動の記録）

データの使い方と保存場所

  • 取得したデータは、開発者自身のPC上にだけ保存し、開発者本人のトレーニングと体調の記録・分析にのみ使います。
  • データを第三者に販売・共有・公開することはありません。広告にも使いません。
  • 分析のために、データの一部をAIサービス（Anthropic の Claude、Google の Gemini）に送ることがあります。これは開発者本人が自分のデータについて質問するためだけに行います。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用と移転は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

アクセスの取り消し

本ツールへのアクセスは、Google アカウントのサードパーティによるアクセスからいつでも取り消せます。

Privacy Policy (English summary)

Training Note Health is a personal tool used only by its developer to view the developer's own data. It requests read-only access to sleep, health metrics (resting heart rate, heart rate variability) and activity (steps, exercises) from the Google Health API. The data is stored only on the developer's own computer and used only for the developer's personal training and health records. It is never sold, shared, published or used for advertising. Parts of it may be sent to AI services (Anthropic's Claude, Google's Gemini) solely so the developer can ask questions about the developer's own data. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at Google Account third-party access.
