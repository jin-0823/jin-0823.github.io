Training Note Health

個人用のトレーニング記録ツール / A personal training log tool

Training Note Health は、開発者本人が自分のスマートウォッチ（Google Pixel Watch と Garmin）のデータを1つのダッシュボードにまとめるために作った、個人用のツールです。一般には提供していません。

Google Health API から、開発者本人の睡眠・活動・健康指標のデータを読み取り専用で取得し、開発者自身のPC上のダッシュボードに表示します。

Training Note Health is a personal tool built by its developer to combine data from the developer's own smartwatches (Google Pixel Watch and Garmin) into a single dashboard. It is not offered to the public. It reads the developer's own sleep, activity and health metrics from the Google Health API (read-only) and shows them on a dashboard running on the developer's own computer.
